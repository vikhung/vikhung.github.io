這個網站從 2020 年開始，一直是一張很長很長的 Bootstrap 表格——能用，但越寫越難找。
今天起改版：**一天一個資料夾，一篇 Markdown**，要放照片就丟進同一個資料夾。

![這是範例圖片，放在 posts/2026-10-20/cover.svg](cover.svg)

## 以後會寫什麼

- **技術**：開發筆記、踩坑紀錄、指令小抄（舊文章都在這裡）
- **旅遊**：去過的地方、拍到的照片
- **新知**：讀到、看到、學到的有趣東西

## 目錄結構

```text
posts/
├── posts.json            ← 文章索引（由工具自動產生）
├── 2026-10-20/
│   ├── index.md          ← 當天文章
│   └── cover.svg         ← 當天用到的照片
└── 2026-10-21/
    ├── index.md
    ├── DSC_0001.jpg
    └── DSC_0002.jpg
```

## 怎麼發新文章

```bash
node tools/blog.js new 2026-10-21 "今天去了哪裡"   # 建立資料夾與範本
# 編輯 posts/2026-10-21/index.md，照片放同資料夾
node tools/blog.js serve                          # 本機預覽 http://localhost:8080
git add -A && git commit -m "new post" && git push
```

在文章裡引用照片只要寫相對路徑，網站會自動指到當天的資料夾：

```markdown
![富士山下的清晨](DSC_0001.jpg)
```

## 文章裡放照片

先把照片放進當天的資料夾（例如 `posts/2026-10-18/`），再在想出現的位置寫一行，前後各留一個空行：

```markdown
![登山口的入口牌樓](trailhead.jpg)
```

- `[ ]` 裡面只是圖片的**文字說明**，可以隨意寫、也可以留空（照片載入失敗時會顯示它）。
- `( )` 裡面的**檔名**才是關鍵，要和資料夾裡的檔名完全一致（含大小寫與副檔名）。
- 只要寫檔名，網站會自動指到當天的資料夾，不用寫完整路徑。
- 檔名建議用英數字，避免空白和中文。
- 點擊照片可以放大。
- 想要圖說，在圖片下一行用斜體寫：`*早上七點半的登山口*`。
- 想讓照片成為首頁列表的縮圖，在文章最上面的設定加一行 `cover: trailhead.jpg`。

## 文章裡放影片

### YouTube 連結

直接寫成 Markdown 連結，讀者點了會另開新分頁觀看：

```markdown
[▶ 觀看皇帝殿縱走影片](https://www.youtube.com/watch?v=影片ID)
```

手機拍的長影片，建議先上傳到 YouTube（可設成「不公開」），再用連結分享，不要直接放進 repo。

### 目前還不支援的做法

- **直接嵌入 YouTube 播放器**（`<iframe>`）：網站為了安全會過濾掉 iframe，所以目前貼了不會顯示。需要的話得另外修改網站程式，只放行 YouTube 網址。
- **把影片檔放進資料夾，用 `<video controls src="trail.mp4"></video>` 播放**：我還沒有實際測試過。另外 GitHub 單一檔案上限是 100 MB，手機影片很容易超過。
